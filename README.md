# Trabajo-Final-ITLA
Se trata de mi proyecto final de el curso de Programacion del ITLA
# Nombre del proyecto

**Sistema Básico de Calificaciones**

## Descripción

Este proyecto consiste en un programa básico desarrollado en Python que permite trabajar con un grupo de calificaciones almacenadas dentro de un arreglo o lista.

El programa fue creado con el objetivo de practicar el uso de arreglos, índices, ciclos, condiciones y operaciones sencillas dentro de Python. A través de estas herramientas se pueden consultar las notas, calcular el promedio, identificar la calificación más alta y más baja, contar cuántos estudiantes aprobaron o reprobaron y modificar una calificación específica.

## Objetivo

El objetivo principal del proyecto es aplicar de manera práctica los conceptos relacionados con arreglos o vectores en programación.

También busca reforzar el uso de estructuras como el ciclo `for`, las condiciones `if` y el acceso a elementos mediante índices, permitiendo comprender cómo se puede almacenar y procesar información de una forma más organizada dentro de un programa.

## Lenguaje utilizado

El programa fue desarrollado utilizando **Python**.

Python fue seleccionado porque posee una sintaxis sencilla y fácil de comprender, lo que permite trabajar de manera clara con listas, ciclos, condiciones y operaciones matemáticas.

## Funcionalidades desarrolladas

El programa permite realizar las siguientes funciones:

- Almacenar varias calificaciones dentro de una lista.
- Mostrar todas las calificaciones registradas.
- Acceder a una calificación específica utilizando su índice.
- Calcular el promedio de las calificaciones.
- Identificar la calificación más alta.
- Identificar la calificación más baja.
- Contar la cantidad de estudiantes aprobados.
- Contar la cantidad de estudiantes reprobados.
- Modificar una calificación específica.
- Mostrar el arreglo actualizado después de realizar el cambio.

## Instrucciones para ejecutar el programa

Para ejecutar el programa es necesario tener Python instalado en la computadora.

Primero se debe copiar el código y guardarlo en un archivo con extensión `.py`.

Por ejemplo:

`calificaciones.py`

Después se puede ejecutar desde un entorno de desarrollo como Visual Studio Code, IDLE o PyCharm.

También puede ejecutarse utilizando la terminal o símbolo del sistema con el siguiente comando:

`python calificaciones.py`

Al ejecutar el archivo, el programa mostrará en pantalla las calificaciones registradas y los resultados de las diferentes operaciones realizadas.
